MODULE // MECHANICS

Shoot a wall, and that specific chunk blows up. Drop a C4, and you are making a new doorway. The match stays server-authoritative, so everyone sees the same breach instead of fake client-side destruction.
Movement leans into the classics. Bunny hopping works. Air strafing works. If you master the momentum, you can cross the map in seconds. It takes practice, and the skill ceiling is high.

MODULE // MODDING

Yes. Because the game is voxel-based, map building is straightforward to learn. Official tooling and workflows for community-made maps are planned.
The modding API supports extensive scripting. Want to make a mode where everyone only has RPGs and 1 HP? Go for it. The public docs are hidden for now while that work gets cleaned up.
